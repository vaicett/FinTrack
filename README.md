# FinTrack

Telegram-бот для учёта личных финансов. Счета, доходы и расходы по категориям, статистика и цели накоплений.

> 🚧 **В разработке.**

## Стек

- TypeScript
- Node.js
- Telegraf
- PostgreSQL

## Что будет уметь

- Несколько счетов: банк, наличные и свои
- Учёт доходов и расходов по категориям
- Переводы между счетами
- История операций с фильтрами и пагинацией
- Статистика за день, неделю, месяц и произвольный период
- Финансовые цели с прогрессом накоплений
